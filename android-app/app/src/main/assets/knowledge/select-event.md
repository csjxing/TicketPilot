# 搜索演出，选择场次和票价

## 少手填，先从真实页面选择

在助手里输入艺人名或演出名，可以加城市，然后点“去大麦搜索”。助手会切到真实大麦搜索；出现结果提醒后，回到助手选择正确项目。

有些手机会阻止后台自动打开助手。此时点击“票务助手 · 演出选择”的通知返回，不必一直等页面自动跳回。

## 按这个顺序核对

1. 项目：看完整演出名称和城市，避免选到同一艺人的其他站。
2. 场次：选择完整日期和开演时间。
3. 票价：每格显示金额和读取状态，勾选一个或多个接受的票面价；当前版本只支持 1 张。
4. 总额：核对最高可接受总额，以及停止检查的时间。

到演出详情后，如果助手提示你点“立即预订”或打开票档，请在大麦手动点一次。助手发现票档页后会继续读取。这个入口仍有一次人工交接。

## 已经打开大麦目标页了

可以使用“直接读取当前页面”。助手按系统桌面的方式打开大麦，等前台稳定和页面停止变化后再读取，总等待上限仍为 20 秒。等待时保持页面可见，避免同时手动切换场次。当前最终包已有温州两日期读取与首场到票价网格的真实助手证据，完整搜索到保存仍未验收；不能保证系统总会保留原页面。如果回到了首页或其他页面，请按提示重新打开原演出，再重读，不能将跳转成功当作场次已经读取。

助手只显示本次能读到的结果。没有显示的场次或票档不代表不存在；可以先在大麦展开相关内容，再重新读取。

## 遇到“预约抢票”页面

已加入预售预约目录识别。2026-10-26 的温州练习中，最终包读出 10 月 31 日、11 月 1 日两个 19:00 场次，并完成首场点击、核对和六档票价展示，读取时全部缺货。第二场点击在此前诊断包通过，未冒充最终包复测；完整搜索到保存及购买流程未验收。先分清开售日期时间和演出日期时间：开售提示只说明何时开始卖票，不是开演时间。能看到场次或票价不等于已有库存，也不等于已预约或锁票。

当前目录练习只核对可见场次与票价，不点击最终预约确认，不保存或启动未核对的购票目标。若读取失败，查看停止标题下方的具体原因，再按提示重读；不要反复点击最终“确定”尝试绕过。

## 保存之后

选择票价后点“核对这份计划”，在票根上核对场次、接受票价、1 张和实付上限，确认无误再点“保存到计划”，返回计划页核对购票条件。修改票价可返回点选；修改场次会重新读取大麦，不能用旧目录冒充新结果。保存只更新目标，不开始监控、不选择观演人，也不创建订单。开始前仍需回到当前大麦页面，核对演出和日期没有变。

“预售”“售票中”、票价可见、按钮可点击，都不能单独证明有票。页面缺失、没加载或读取失败会记为未知，不会算成缺货。

## 什么时候才手动填写

只有真实页面读取不适用、而你能核对完整信息时，才使用“我的 → 高级工具”中的手动填写。关键词应取自演出标题；城市、日期、时间必须与大麦一致。停止时间是监控停止时间，不是订单付款期限。

历史测试项目只是测试记录，不会成为新任务的购买授权。换电脑开发不需要重新导入手机目标；如使用备用的配置恢复，导入草稿仍须从真实大麦重新选择核对。

## 让领航员帮我选

每一步旁边都有“让领航员……”入口，带入当前来源与相关问题。领航员会先指出当前步骤和下一步，你也可以描述关心的日期、预算或票价差异。主动发送前确认摘要里是正确的公开演出、场次和读取时间；仅打开领航员不会请求模型。

如果需要分析当前票档，主动点“读取大麦当前页”，按提示切到目标页面，让助手做一次本机读取，再返回 AI 页查看摘要。没有读到的信息保持未知，不能由模型补成当前库存。

可以直接描述需求，让模型整理出目标草稿。先检查草稿，只有你点击确认才保存；保存后可在“我的 → 高级工具”中调整。保存后任务保持暂停，仍需从真实大麦重新选择并核对演出、场次和票档。草稿仅支持 1 张以及提醒或到确认页暂停模式，不能选择观演人、点击票档或开始监控。不要把身份证号、电话号码、账号或 API Key 写进问题。
