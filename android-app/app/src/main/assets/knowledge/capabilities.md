## 大麦升级会不会影响

可能会。票务助手读取的是真实可见页面，依赖布局、文字、控件范围和选中状态。页面变化时会暂停或报告未知；不能承诺大麦稍作升级后仍能继续使用。

代码已经分离页面适配与决策，后续可以定向维护。升级大麦或调整适配后，先用小范围界面测试核实，不直接沿用历史成功结论。

## 隐私与本机运行

普通规则判断和文字识别在手机本地完成。v0.1.11 增加网络权限，AI 模块仅在用户主动启用并发送时调用模型；不开启 AI 也能使用普通监控和离线说明。大麦仍由其官方应用联网处理账号、库存和订单。

运行截图用于内存中的本地识别，不会写成相册或随 AI 请求上传。通用检查记录不保存观演人、证件号、订单正文或完整页面文字。内置知识不含账户资料。

当前没有 Dot、短信或其他手机推送，也没有云端模型自动接管。付款始终由用户在官方流程中完成。

## AI 可以帮助什么

可选 AI 提供配置建议、场次比较、票档解释和异常分析。你在手机填写接口、模型名和 API Key，先查看实际发送内容和接收服务，再主动发送。它可以把自然语言整理为目标草稿，由你检查并确认保存；草稿保持暂停并等待真实大麦重新核对。它不直接启动监控、点击大麦或自动提交订单，也不会在发生阻塞时自行联网。

“读取大麦当前页”是一次明确请求：随后切到大麦，由本机读取允许的日期、时间、价格、票档状态等有限摘要，必要时使用本机 OCR。截图、完整文字树和坐标不留在 AI 摘要里；账户、订单、验证码等页面只提供类别。回到 AI 页后再预览是否发送。页面摘要带时间，过期或未知内容不能证明当前库存。

你可以编辑模型建议并确认保存为本机经验笔记。它们只是未验证参考，后续手动分析时才使用；不会训练模型权重、更新适配器或改变抢票规则。模型可能误判，配置和库存仍以真实大麦当前页面为准。真实模型连通、建议质量和成本需要使用你选定的服务分别验收。

API Key 用 Android Keystore 加密保存，不包含在知识库、日志、源码包或目标备份中。模型服务接收你确认发送的内容，可能计费；每日调用次数及单次输出上限只是本机限制，不是免费承诺。

内置 OCR 依赖 ML Kit。其官方数据说明披露 SDK 诊断数据收集；本工程尚未验收新增联网权限后的实际 SDK 诊断行为。因此“关闭 AI”表示不发起模型请求，不保证整个应用完全没有网络通信。
